# BissauService

Marketplace web app that connects clients with local service providers in Guinea-Bissau.

The platform connects clients with local service providers in Guinea-Bissau.

Features:

Users can sign up as clients or service providers.

Service providers create a profile with:

- name

- service category

- phone

- location

- description

- photo

Clients can create service requests with:

- category

- description

- location

The platform shows service providers by category.

Each provider has a profile page with contact button (WhatsApp).

Include a simple rating and review system.

Use Supabase for database and authentication.

Clean mobile-first design.
